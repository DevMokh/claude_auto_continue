# خطة الاختبار على جهاز حقيقي (لم تُنفَّذ بعد)

الاختبارات الآلية في `test/` تستخدم **شاشات محاكاة** فقط. كل بند هنا يحتاج هاتفك الحقيقي، وكل نتيجة تُسجَّل في `TEST_REPORT.md`.

## 0) التجهيز
- Android 14+ ، تطبيق Claude الرسمي مثبّت ومسجَّل الدخول.
- ثبّت `claude-auto-continue-debug.apk` (السماح بالتثبيت من مصدر خارجي).
- أندرويد 13+: افتح معلومات التطبيق > ⋮ > "السماح بالإعدادات المقيّدة" قبل تفعيل Accessibility.
- تأكد من اسم الحزمة: `adb shell pm list packages | grep anthropic` (المتوقع `com.anthropic.claude`). إن اختلف عدّل `UiPatterns.claudePackage` و`ClaudeAccessibilityService.CLAUDE_PACKAGE` و`accessibility_service_config.xml`.

## 1) المعايرة (الأهم، قبل أي شيء آخر)
| # | الخطوة | النتيجة المتوقعة | الحالة |
|---|--------|------------------|--------|
| 1.1 | الإعدادات > "التقاط شجرة الشاشة" ثم افتح Claude على محادثة عادية | يظهر حقل إدخال واحد قابل للتحرير (`editable`) | ☐ |
| 1.2 | التقاط أثناء كتابة Claude للرد | يظهر زر إيقاف (Stop) بنص/وصف يطابق `stopLabels` | ☐ |
| 1.3 | التقاط بعد كتابة نص في الحقل | يظهر زر إرسال يطابق `sendLabels` | ☐ |
| 1.4 | التقاط عند ظهور رسالة حد الاستخدام | نص الرسالة يطابق `usageLimitPhrases`، وحالة الحقل (مفعّل/معطّل) مسجّلة | ☐ |
| 1.5 | التقاط عند ظهور زر Continue (إن ظهر) | النص مطابق لـ `continueLabels` | ☐ |

إن لم يطابق شيء: عدّل `lib/core/constants/ui_patterns.dart` (قوائم بحروف صغيرة) وأعد البناء.
